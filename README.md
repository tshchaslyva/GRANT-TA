# GRANT-TA — грант «Власна справа» (масштабування), ФОП Федоренко Т. А.

Матеріали для повторного подання заяви після відмови за версією І (вересень 2026).

| Файл | Що це |
|---|---|
| `01_Аналіз_відмови_та_план_повторного_подання.md` (+ `.docx`, `.pdf`) | головний документ: чому відмовили, як рахують бали, що змінено, що робити далі |
| `02_БП_Федоренко_версія_2.xlsx` + `.pdf` | виправлений бізнес-план в офіційному шаблоні Дії (XLSX + PDF подаються разом) |
| `03_Фінансова_модель_і_бали.xlsx` | допоміжна модель: помісячний план, сценарії, калькулятор балів, ліміти п. 7 (не подається) |
| `04_Чеклист_подання_та_співбесіда.md` | строки, документи, цифри для заяви в Дії, підготовка до співбесіди |
| `tools/` | скрипти: `model.py` (цифри), `build_bp.py` (збирання форми з чистого шаблону Дії), `verify_bp.py` (незалежна перевірка), `build_model_xlsx.py` (модель) |
| `БП_грант_власна_справа І (1).xlsx`, `FOP_Fedorenko_*` | вихідні матеріали: подана версія І та аналіз ChatGPT від 16.10.2026 |

**Ключові дати:** подавати не раніше 17.02.2027 (6 місяців діяльності ФОП); етап приймання 16–25 лютого 2027.

**Перед поданням:** заповнити у `02_…xlsx` три поля «[уточнити]» (B11, B16, B51), оновити дату (B78), сформувати PDF з XLSX, підписати КЕП.

Відтворити файли: `python3 tools/build_bp.py <шаблон_Дії.xlsx> 02_БП_Федоренко_версія_2.xlsx`, потім перерахувати у Excel/LibreOffice і перевірити `python3 tools/verify_bp.py <перерахований.xlsx> <шаблон_Дії.xlsx>`.
